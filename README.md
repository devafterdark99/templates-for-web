## ✦ About Creator Lab

**Creator Lab** is a creative web-template collection built around interactive interfaces, visual storytelling, playful animations and customizable digital experiences.

Instead of ordinary static pages, these concepts explore different ways to make websites feel alive — through animated transitions, interactive elements, immersive layouts and distinctive visual identities.

Whether you want to experiment with a game-inspired interface, build a fictional operating system or tell a story through an interactive journey, Creator Lab gives you a starting point to explore and customize.

> ✨ Built with the fundamentals of the web: HTML, CSS and JavaScript.

## 🚀 Getting Started

Get the project running locally in a few steps.

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Replace the URL with your repository's actual address.

### 2. Open the project

```bash
cd YOUR-REPOSITORY
```

### 3. Launch the website

Open `index.html` in your browser.

For a smoother local development workflow, use the **Live Server** extension in Visual Studio Code.

### 4. Explore the concepts

Browse the available cards, select a concept and explore its interface.

## 🎨 Make It Your Own

Creator Lab is intended to be customized and extended.

### Change the visual identity

Edit `css/styles.css` to experiment with:

- 🎨 Color palettes and gradients
- 🔤 Font families and typography
- 🌫️ Shadows, borders and glass effects
- 🎞️ Animations and transition timing
- 📐 Spacing, layouts and responsive breakpoints

### Update interactions

Edit `js/main.js` to customize:

- 🖱️ Selection behavior
- 💬 Toast notifications
- 🪟 Confirmation dialogs
- 💾 Browser-side preferences
- 🧭 Navigation behavior

### Customize a concept

Open the relevant file inside `themes/` and adjust its content, sections, images, layout and interactions.

**Tip:** When moving or renaming a file, update every corresponding link in the HTML and JavaScript.
